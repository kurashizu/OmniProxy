# Plan: GitHub Actions CI Release

## Goal
Set up GitHub Actions to automatically build Windows and Linux (musl) binaries when a `v*` tag is pushed.

## Files to Create

### `.github/workflows/release.yml`

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    strategy:
      matrix:
        include:
          - target: x86_64-pc-windows-msvc
            os: windows-latest
            ext: .exe
          - target: x86_64-unknown-linux-musl
            os: ubuntu-latest
            ext: ""

    runs-on: ${{ matrix.os }}

    steps:
      - uses: actions/checkout@v4

      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.target }}

      - name: Build client
        run: |
          cargo build --release --manifest-path client/Cargo.toml --target ${{ matrix.target }}
          mkdir -p dist
          cp client/target/${{ matrix.target }}/release/client{{ matrix.ext }} dist/

      - name: Build server
        run: |
          cargo build --release --manifest-path server/Cargo.toml --target ${{ matrix.target }}
          mkdir -p dist
          cp server/target/${{ matrix.target }}/release/server{{ matrix.ext }} dist/

      - name: Package Linux
        if: matrix.os == 'ubuntu-latest'
        run: |
          cp scripts/proxy.sh dist/
          cp README.md dist/
          zip -r socks5-proxy-linux-x86_64-musl.zip dist/

      - name: Package Windows
        if: matrix.os == 'windows-latest'
        run: |
          cp README.md dist/
          Compress-Archive -Path dist -DestinationPath socks5-proxy-windows-x86_64-msvc.zip

      - name: Upload assets
        uses: softprops/action-gh-release@v1
        with:
          files: |
            socks5-proxy-windows-x86_64-msvc.zip
            socks5-proxy-linux-x86_64-musl.zip
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## Key Design Decisions

1. **Tag pattern**: `v*` (e.g., `v0.1.0`, `v1.0.0-beta`)
2. **Windows MSVC**: `x86_64-pc-windows-msvc` target (no extra toolchain needed on windows-latest)
3. **Linux musl**: Static binary, no external dependencies
4. **Zip naming**: `socks5-proxy-{os}-{arch}.zip` (e.g., `socks5-proxy-windows-x86_64-msvc.zip`, `socks5-proxy-linux-x86_64-musl.zip`)
5. **Zip contents**:
   - Linux: `client`, `server`, `proxy.sh`, `README.md`
   - Windows: `client.exe`, `server.exe`, `README.md`
6. **Server LTO**: Already enabled in `server/Cargo.toml` for optimized release builds
