## Files to Modify

### `.github/workflows/release.yml`

**Build section** — add `proxy` to build matrix:
```yaml
- target: x86_64-unknown-linux-musl    # Linux already has proxy
- target: x86_64-pc-windows-msvc        # Windows already has proxy
```

**Build steps** — add proxy compilation (after server build for each platform):
```yaml
- name: Build proxy
  run: |
    cargo build --release --manifest-path proxy/Cargo.toml --target ${{ matrix.target }}
    cp proxy/target/${{ matrix.target }}/release/proxy${{ matrix.ext }} dist/
  shell: bash
```

**Package Linux** — include proxy binary and tun2socks:
```yaml
- name: Package Linux
  run: |
    cp README.md dist/
    cp tun2socks dist/ || true
    zip -r ${{ matrix.zip }} dist/
```

**Package Windows** — include proxy.exe, tun2socks.exe, wintun.dll:
```yaml
- name: Package Windows
  run: |
    cp README.md dist/
    if (Test-Path tun2socks.exe) { cp tun2socks.exe dist/ }
    Compress-Archive -Path dist -DestinationPath ${{ matrix.zip }}
```

**Zip contents (final):**
- Linux: `client`, `server`, `proxy`, `tun2socks`, README
- Windows: `client.exe`, `server.exe`, `proxy.exe`, `tun2socks.exe`, `wintun.dll`, README

(No shell or PowerShell scripts in either zip)
